# StarForge Android 9 — Codespaces launcher

When this codespace starts, the dev container installs dependencies, starts the isolated
mobile test server, and forwards port 8799.

The test server is intentionally safe:
- in-memory test company
- no production ledger
- no real-money operations
- no provider calls
- no external side effects

Open the forwarded **StarForge Android 9 Test Lab** port from the PORTS panel.
